# LeafEvents

Плагин ивентов с лутом для Paper 1.21 и Java 21. Пакет: `com.agent1k`.
PlaceholderAPI 2.11.6 поддерживается как необязательная зависимость.

## Команды

Для всех команд и редакторов необходимо право `leafevents.admin`, по умолчанию доступное операторам.

- `/leafevents` — помощь.
- `/leafevents create <id> <название>` — создать ивент. Название может содержать пробелы, `&` и `&#RRGGBB`.
- `/leafevents menu` — список ивентов с переключением страниц.
- `/leafevents start <id>` — запустить ивент.
- `/leafevents stop <id>` — остановить ивент.

Автодополнение предлагает подкоманды и идентификаторы для `start` и `stop`.
Консоль может создавать, запускать и останавливать ивенты; меню доступны игрокам.

## Редакторы

В списке ивентов ЛКМ открывает редактор лута, ПКМ — редактор шансов.
В редактор лута можно класть предметы и убирать их; изменения сохраняются при закрытии.
Предметы сериализуются средствами Bukkit с метаданными. Новые предметы получают шанс 100%.
Для прежнего предмета в прежнем слоте сохраняется установленный шанс.
Редактировать один ивент одновременно может только один игрок.

Редактор шансов использует управление как в BAirDrop:

- ЛКМ: −1%.
- ПКМ: +1%.
- Shift+ЛКМ: −10%.
- Shift+ПКМ: +10%.

Значения ограничены диапазоном 0–100%. Изменение сохраняется сразу.
Лор редактора добавляется только к отображаемым копиям предметов.
Меню защищено от извлечения предметов, shift-переноса, цифровых клавиш и перетаскивания.
При большом количестве предметов доступны страницы.
Каждый слот лута разыгрывается независимо при старте ивента: 0% никогда, 100% всегда.
Лут запущенного ивента отделён от шаблона, поэтому его редактирование влияет на последующие запуски.

## Конфигурация

При первом запуске создаются `config.yml`, `messages.yml`, `menus/menu.yml`, `menus/event-chance.yml` и папка `events`.
Команда `create` создаёт `events/<id>.yml`. Настройки читаются в память при включении плагина.
Для применения ручных изменений YAML нужен штатный перезапуск сервера.
Не редактируйте YAML одновременно с открытым редактором: сохранение редактора записывает настройки из памяти.

Пример конфигурации созданного ивента:

```yaml
airdrop-settings:
  material: CHEST
  random-spawn: true
  event-world: [world]
  location-spawn:
    enabled: false
    coordination:
      x: 0
      y: 0
      z: 0
  spawn-time: 500
  stop-time: 1500
  online: 1
  spawn-radius: 1000
inventory-settings:
  name: '&fТестовый аир'
  size: 54
  inventory-loot: {}
```

`spawn-time` — интервал автоматической попытки запуска в секундах, отсчитываемый после остановки.
`stop-time` — длительность ивента в секундах. `online` проверяется и при ручном запуске.
При недостаточном онлайне или отсутствии безопасного места автоматическая попытка повторяется через `spawn-time`.
`inventory-settings.size` — число слотов, кратное 9, от 9 до 54. Нумерация слотов начинается с нуля.
Лут сохраняется как `inventory-settings.inventory-loot.<slot>.item` и `.chance`.

При `location-spawn.enabled: true` используются заданные координаты в одном из разрешённых загруженных миров.
Иначе `random-spawn: true` выбирает безопасную поверхность в радиусе `spawn-radius` от центра границы мира.
Поиск ограничен 64 попытками. Место должно находиться в границе мира, над твёрдым блоком, с двумя свободными блоками воздуха.
При `random-spawn: false` ручной запуск размещает ивент у ног игрока в разрешённом мире; автоматический запуск в этом режиме отключён, если не заданы фиксированные координаты.
Для мира с несколькими разрешёнными именами выбирается случайный загруженный мир.

Ивент открывается ПКМ по его блоку. Инвентарь общий для всех игроков.
На время работы чанк удерживается загруженным; блок защищён от разрушения, взрывов, огня и поршней.
При остановке или штатном отключении плагина открытые инвентари закрываются, остатки лута удаляются, исходный блок восстанавливается.
Принудительное завершение процесса сервера не вызывает обработчик отключения.

## Действия меню и сообщений

- `[message] <текст>` — отправить сообщение.
- `[open-inventory]` — открыть редактор лута выбранного ивента.
- `[open-menu] <имя>` — открыть меню из папки `menus` по имени YAML без расширения.
- `[chance] <изменение>` — изменить шанс выбранного предмета в редакторе шансов.
- `[page] <изменение>` — сменить страницу текущего меню.
- `[close]` — закрыть меню.

Ключи действий: `left_click_action`, `right_click_action`, `shift_left_click_action`, `shift_right_click_action`.
Для совместимости с примерами ТЗ поддерживаются также `left-action_click`, `left_action_click`, `right_action_click`, `right-action_click`.
Пустые строки сообщений отправляют пустую строку в чат.
В `menu-settings.events.slot` задаются неповторяющиеся слоты карточек.
Кнопки в `items` имеют `material`, `name`, `lore`, `slot` и действия; их слоты должны быть вне слотов карточек.
Тип меню `events` отображает ивенты, тип `chance` — предметы выбранного ивента.

## Плейсхолдеры

Встроенные значения: `%leafevents_event_name%`, `%leafevents_event_id%`, `%leafevents_coordination%`, `%leafevents_world%`, `%leafevents_state%`.
Координаты и мир доступны для запущенного ивента. Пользовательские текстовые плейсхолдеры задаются в секции `placeholders` файла `messages.yml`.
Не переопределяйте встроенные имена и не создавайте циклические ссылки.
В собственных меню и сообщениях значения подставляются без PlaceholderAPI.
С PlaceholderAPI дополнительно работают плейсхолдеры других плагинов и зарегистрировано расширение `leafevents`.
Внешние запросы используют последний выбранный игроком ивент; время жизни контекста задаётся `placeholder-context-ttl-seconds` в `config.yml`.
Без выбранного контекста название, ID, координаты и мир пустые; состояние — «остановлен».
Контекст удаляется по TTL и при выходе игрока.

## Проверка исходников

Сборка и запуск сервера не выполнялись по просьбе заказчика.
Проведён синтаксический разбор Java без компиляции проекта и проверка формата YAML/XML.
Совместимость с API и поведение на сервере требуют отдельной сборки и проверки.
Механика редактора изучена по открытому репозиторию https://github.com/By1337/BAirDrop, реализация LeafEvents написана самостоятельно.
